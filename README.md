# Kaysha Kitten

**Operations & Technical Leader | Smarter Systems, Leaner Operations | Data, Automation + AI Enablement**

Never surface level. The details other people skip are where problems hide and where wins come from. I catch them, fix them, and when something's missing, I learn it and build it.

Based in Denver. Across ecommerce brands, client builds, and platform migrations, I've handled the operations side and the technical side, often at the same time. That work includes:

- A marketplace with 1,000+ vendors and 2M+ transactions
- A data migration of 20 million+ data points
- Full rebuilds of failing systems

## What I do

- Work across the full stack in whatever language the system calls for: back end, databases, and front end UX/UI
- Design custom integrations between platforms that were never meant to talk to each other
- Keep production data reliable, from backups and performance to integrity and recovery
- Reconcile financial data across systems, from payouts and commissions to monthly close
- Find silent failures before they cost revenue
- Build custom automation and tooling that turn daily operations into repeatable SOPs
- Enable teams with AI: agents, skills, and workflows built around how they already work

**How I work:** Learn it, build it, document it, automate it. Every new platform becomes a tool, not a blocker.
